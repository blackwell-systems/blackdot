## Critical Findings

### 1. os.Exit() Bypass in Command Handlers ✅ RESOLVED

**Severity:** Critical  
**Check:** `panic_recovery`, `error_wrapping`  
**Tool:** Grep  
**Status:** Fixed in commit d656548  

Three `os.Exit(1)` calls prevent graceful error handling and break testability:

**Location 1:** `internal/cli/tools.go:48`
```go
cmd.RunE = func(c *cobra.Command, args []string) error {
    if err := checkToolFeature(toolName); err != nil {
        fmt.Fprintln(os.Stderr, err)
        os.Exit(1)  // ← Should return err
    }
    return originalRunE(c, args)
}
```

**Location 2:** `internal/cli/tools.go:56`
```go
cmd.Run = func(c *cobra.Command, args []string) {
    if err := checkToolFeature(toolName); err != nil {
        fmt.Fprintln(os.Stderr, err)
        os.Exit(1)  // ← Should panic or convert to RunE
    }
    originalRun(c, args)
}
```

**Location 3:** `internal/cli/features.go:594`
```go
Info("Feature '%s' is disabled", name)
os.Exit(1)  // ← Should return error
return nil  // ← Unreachable
```

**Impact:** Cannot unit test these code paths; violates Cobra's error handling convention.

**Recommendation:**  
Replace `os.Exit(1)` with `return err` in RunE functions. For Run functions, convert to RunE or propagate errors via panic (caught by Cobra).

### 5. No Context Propagation ✅ RESOLVED

**Severity:** High  
**Check:** `context_propagation`  
**Tool:** Grep  
**Status:** Fixed in commits 14ad477, 619352b (14 vault functions updated)

**Finding:** Zero usage of `context.Context` across 23,500 lines of Go code.

**Impact:**
- Long-running vault operations (Bitwarden CLI calls) cannot be cancelled
- No timeout protection on HTTP-like operations or subprocess execution
- Cannot propagate cancellation from Cobra command context down to workers

**Examples of affected operations:**
- `internal/cli/vault.go` — vaultmux backend operations (no timeout)
- `internal/cli/tools_*.go` — subprocess execution (cannot cancel)
- `internal/template/engine.go` — file rendering (no cancellation)

**Recommendation:**  
Add `context.Context` parameter to exported functions in:
1. `internal/cli/vault.go` — pass through to vaultmux
2. `internal/template/engine.go` — `Render(ctx context.Context, ...)`
3. Tool subcommands that spawn long-running processes

Use `cmd.Context()` in Cobra RunE functions (available since Cobra v1.2).

### 6. Init Side Effects

**Severity:** Medium  
**Check:** `init_side_effects`  
**Tool:** Grep

Three packages use `init()` for global state initialization:

**1. `internal/cli/root.go:78`**
```go
func init() {
    cobra.OnInitialize(initConfig)
    // ... registers all commands
}
```
**Issue:** Commands registered during import; side effect before main() runs.  
**Mitigation:** Standard Cobra pattern; acceptable but prevents selective initialization.

**2. `internal/cli/config.go:20`**
```go
func init() {
    if xdg := os.Getenv("XDG_CONFIG_HOME"); xdg != "" {
        configLayerUser = filepath.Join(xdg, "blackdot", "config.json")
        configLayerMachine = filepath.Join(xdg, "blackdot", "machine.json")
    }
}
```
**Issue:** Reads environment at import time; cannot be overridden in tests.

**3. `internal/cli/sync.go:37`**
```go
func init() {
    home, _ := os.UserHomeDir()
    syncableItems["SSH-Config"] = filepath.Join(home, ".ssh/config")
    // ... 4 more items
}
```
**Issue:** Silently ignores `os.UserHomeDir()` error; paths are invalid if home dir unavailable.

**Recommendation:**  
Move initialization to lazy evaluation or explicit setup functions. For `sync.go`, check the error:
```go
home, err := os.UserHomeDir()
if err != nil {
    log.Fatal(err) // or return error if in main
}
```

### 8. Missing Error Context

**Severity:** Medium  
**Check:** `error_wrapping`  
**Tool:** Grep

212 instances of `return err` without wrapping (from 25 files). While some errors are properly wrapped with `fmt.Errorf(..., %w, err)`, many error paths return raw errors, losing context.

**Example Pattern (common in tools_*.go):**
```go
cmd := exec.Command("aws", "sso", "configure", "list-profiles")
output, err := cmd.Output()
if err != nil {
    return err  // ← Lost: which AWS command failed? what were the args?
}
```

**Recommendation:**  
Wrap errors at package boundaries with context:
```go
if err != nil {
    return fmt.Errorf("aws sso list-profiles: %w", err)
}
```
